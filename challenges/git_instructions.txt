===== CHALLENGE 5: GIT MYSTERY =====

Your task is to find a secret message hidden in the Git commit history of a repository.

INSTRUCTIONS:
1. Clone the repository using the command below:
   git clone https://github.com/ing-tech-hunt/git-mystery.git

2. Navigate to the repository:
   cd git-mystery

3. Examine the Git commit history to find the hidden message.
   HINT: Look at the first letter of each commit message.

4. Once you find the secret message, enter it as the password on the challenge page to unlock the next challenge.

DETAILED STEPS:

1. First, view the commit history:
   git log

2. You'll see a series of commits with seemingly normal messages.

3. Pay special attention to the first letter of each commit message.
   For example, if the commit messages are:
   - "Update README with project description"
   - "Simplify login process"
   - "Enhance security features"
   
   The first letters would be "U", "S", "E".

4. To make this easier, you can use a Git command to extract just the commit messages:
   git log --pretty=format:"%s"

5. You might want to write a small script to extract the first letter of each commit message:
   git log --pretty=format:"%s" | awk '{print substr($0,1,1)}' | tr -d '\n'

6. The resulting string will be the hidden message and the password for the next challenge.

ADDITIONAL INFORMATION:

- The repository contains a simple web application, but the code itself is not relevant to the challenge.
- The commit history has been carefully crafted to hide the message.
- There are approximately 20-25 commits in the repository.
- The commits are in chronological order, so read them from oldest to newest (bottom to top in the git log output).

Good luck!

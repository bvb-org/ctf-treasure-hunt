# Challenge Ideas

## Initial Ideas

1. **QR Code Puzzle**
   - **Description:** Decode a series of QR codes to reveal a hidden message
   - **Difficulty:** Medium
   - **Points:** 250
   - **Category:** Cryptography
   - **Hint:** Look for patterns in how the fragments connect together

2. **Command Line Escape**
   - **Description:** Use command line skills to navigate through a virtual system and find the exit code
   - **Difficulty:** Hard
   - **Points:** 300
   - **Category:** System Administration
   - **Hint:** Check hidden files and directory permissions for clues

3. **API Chain Reaction**
   - **Description:** Follow a chain of API endpoints to reach the final destination
   - **Difficulty:** Medium
   - **Points:** 250
   - **Category:** Web Development
   - **Hint:** Each response contains the URL or path to the next endpoint

4. **Hardware Puzzle Box**
   - **Description:** Manipulate a virtual hardware interface by writing code to unlock a digital puzzle box
   - **Difficulty:** Hard
   - **Points:** 300
   - **Category:** Hardware Programming
   - **Hint:** The sequence of operations matters more than individual actions

5. **Reverse Engineering**
   - **Description:** Analyze a compiled program to determine what input produces the expected output
   - **Difficulty:** Hard
   - **Points:** 300
   - **Category:** Software Engineering
   - **Hint:** Try different input patterns and observe how the output changes

6. **Steganography Challenge**
   - **Description:** Extract hidden messages concealed within image files
   - **Difficulty:** Medium
   - **Points:** 250
   - **Category:** Security
   - **Hint:** Look beyond what's visible to the naked eye

7. **Blockchain Decoder**
   - **Description:** Analyze a simple blockchain to find hidden messages in the transaction data
   - **Difficulty:** Hard
   - **Points:** 300
   - **Category:** Blockchain
   - **Hint:** The order of blocks and their hash values contain important clues

8. **AI Whisperer**
   - **Description:** Extract information from an AI assistant by finding the right prompts
   - **Difficulty:** Medium
   - **Points:** 250
   - **Category:** Artificial Intelligence
   - **Hint:** Certain keywords trigger special responses from the AI

9. **SQL Detective**
   - **Description:** Write SQL queries to extract information from a database and solve a mystery
   - **Difficulty:** Medium
   - **Points:** 250
   - **Category:** Databases
   - **Hint:** Join multiple tables to reveal the complete picture

10. **IoT Network Puzzle**
    - **Description:** Program virtual IoT devices to communicate in a specific sequence
    - **Difficulty:** Hard
    - **Points:** 300
    - **Category:** Internet of Things
    - **Hint:** Each device needs to receive and send specific messages
